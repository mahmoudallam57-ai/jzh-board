# دليل التشغيل — لوح الجزيرة الحمراء

## المكوّنات
- **Vercel**: يقدّم `public/` (الصفحة والصور والفيديو) ودالتي الخادم `api/s/[action].js` للطلاب و`api/t/[action].js` للمعلّم.
- **Supabase** (مشروع `jzh-board`، المعرّف `dpnleuihznptumipaffo`، مومباي `ap-south-1`): الجداول في `supabase/migrations/0001_init.sql`. RLS مفعّل بلا سياسات، فلا يصل إلى البيانات إلا مفتاح الخدمة من الدوال.
- المتصفح لا يحمل أي مفتاح. جلسة الطالب كوكي `jzh_s` مدّتها 8 ساعات، وتوكن المعلّم في ذاكرة الصفحة فقط ويخرج تلقائياً بعد 15 دقيقة بلا نشاط.

## متغيّرات البيئة في Vercel (Production و Preview)
| المفتاح | من أين | سرّي؟ |
|---|---|---|
| `SUPABASE_URL` | `https://dpnleuihznptumipaffo.supabase.co` | لا |
| `SUPABASE_ANON_KEY` | Supabase → Project Settings → API Keys (publishable/anon) | لا |
| `SUPABASE_SERVICE_KEY` | Supabase → Project Settings → API Keys → **service_role / secret** | **نعم — يُلصق في Vercel مباشرة، لا في المحادثة** |
| `SESSION_SECRET` | سلسلة عشوائية ≥ 32 حرفاً (`openssl rand -base64 48`) | نعم |
| `TEACHER_EMAILS` | بريد المعلّم (أو أكثر مفصولة بفاصلة) | لا |

## خطوات لمرة واحدة في Supabase
1. **أوقف التسجيل الذاتي**: Authentication → Sign In / Providers → أطفئ «Allow new users to sign up». (لا يحتاج اللوح تسجيلاً عاماً.)
2. **حساب المعلّم**: Authentication → Users → Add user → Create new user → البريد + كلمة مرور تختارها أنت + فعّل «Auto Confirm User».
3. بعد أول دخول للوحة المعلّم: تبويب «أدوات وإعدادات» → «الشعب» → اكتب شعبك (`7/3 | السابع ٣`) واحفظ. قبل ذلك تعمل البوابة بالوضع القديم (اسم فقط، ضيف).

## مهام معتادة
- **طالب نسي رمزه**: لوحة المعلّم → الطلاب → اسمه → «ثبّت رمزاً جديداً». تنتهي جلساته القديمة تلقائياً.
- **سجلّان لطالب واحد**: افتح أحدهما → «ادمج السجلّ المختار…» → يُدمج التقدّم كلّه ولا يضيع إنجاز.
- **اعتماد شهادة**: جدول الطلاب → «اعتمد». تنفتح على جهاز الطالب خلال دقيقة أو عند فتح الصفحة.
- **نشر الإعدادات**: اضبط «إظهار وإخفاء» ثم «أدوات وإعدادات» → «انشر» لشعبة أو لكل الشعب.
- **تدوير الأسرار**: غيّر `SESSION_SECRET` في Vercel ثم أعد النشر (تنتهي كل جلسات الطلاب)؛ مفتاح الخدمة يُدوَّر من Supabase ثم يُحدَّث في Vercel.

## الحدود
- 5 محاولات دخول خاطئة للطالب في 15 دقيقة ثم قفل 15 دقيقة (عدّاد ذرّي في `hit_attempt`).
- 200 فشل دخول لكل عنوان IP في 15 دقيقة (المدرسة تشارك عنواناً واحداً)، و100 محاولة تسجيل.
- المعلّم: 5 محاولات لكل بريد، و50 فشلاً لكل IP في مجال منفصل.

## الاختبارات
- `npm test` — وحدات الخادم والدمج (اختبارات Supabase الحيّة تعمل عند ضبط `SUPABASE_URL` و`SUPABASE_SERVICE_KEY`).
- `python3 -m pytest tests/ui -q` — واجهة Playwright بخادم وهمي.
- بعد تعديل كتلة `SYNC` في الصفحة: `python3 scripts/gen-merge.py`.
